# AI Changemakers 100x100 — Багийн портал

AI Academy Asia-гийн "AI Changemakers 100x100" (2026) хөтөлбөрийн Capstone Project багийн ажлыг хялбар болгох вэб систем.

## Хурдан эхлэх

```bash
# 1. Хамаарлуудыг суулгах
pip install -r requirements.txt

# 2. .env файл үүсгэх (жишээнээс хуулна)
cp .env.example .env
# ADMIN_PASSWORD болон SECRET_KEY-г өөрчил

# 3. Excel өгөгдөл импортлох
python manage.py import data/Багт\ хуваасан.xlsx --track professionals
# Оюутнуудын файлыг ижил аргаар:
# python manage.py import data/оюутнууд.xlsx --track students

# 4. Серверийг ажиллуулах
python run.py
# Хөгжүүлэлтийн горим: python run.py --reload
# Сүлжээнд нээх: python run.py --host 0.0.0.0
```

Хөтөч дээр http://localhost:8000 нээнэ.

## Хэрэглэгчид

### Суралцагч
- http://localhost:8000 — утас эсвэл имэйлээрээ нэвтэрнэ
- Багаа, гишүүдээ, 9 алхмын явцаа харна

### Зохион байгуулагч (Админ)
- http://localhost:8000/admin — `.env` доторх `ADMIN_PASSWORD`-аар нэвтэрнэ
- Бүх багийн нэг хүснэгт, шүүлтүүр, анхааруулга, Excel экспорт
- Гишүүн шилжүүлэх, ахлагч томилох, слот засах, зарлал бичих

## Импорт

```bash
python manage.py import <файл.xlsx> --track professionals
python manage.py import <файл.xlsx> --track students
```

Импорт дахин ажиллуулахад аюулгүй (upsert). Суралцагчийн мэдээллийг шинэчилнэ, багуудын оруулсан зүйлийг (ахлагч, төсөл, сонгосон өдөр) устгахгүй. Админ хуудаснаас мөн файл оруулж болно.

## Нөөцлөх

```bash
python manage.py backup
```

Сервер асах бүрт өдөр тутмын автомат нөөц `backups/` хавтаст хийгдэнэ. 7 хоногоос хуучин нөөц автоматаар устна.

## Cloud руу байршуулах

Docker ашиглах:

```bash
docker build -t changemakers .
docker run -p 8000:8000 -v ./data:/app/data -v ./backups:/app/backups changemakers
```

Эсвэл Render, Railway, Fly.io дээр шууд `.env` тохируулаад deploy хийнэ.

## Тохиргоо (.env)

| Хувьсагч | Тайлбар | Өгөгдмөл |
|----------|---------|----------|
| `ADMIN_PASSWORD` | Админ нууц үг | changeme123 |
| `SECRET_KEY` | Session-ийн нууц түлхүүр | (dev key) |
| `DATABASE_URL` | SQLite файлын зам | sqlite:///data/capstone.db |
| `SHOW_CONTACT_INFO` | Багийн гишүүдийн холбоо барих мэдээлэл харуулах | true |
| `RATE_LIMIT_PER_MINUTE` | Нэвтрэх оролдлогын хязгаар (IP бүрт) | 10 |

## Технологи

- Python 3.11+ / FastAPI / Jinja2
- SQLite (SQLAlchemy ORM)
- openpyxl (Excel уншиж, бичих)
- Mobile-first HTML/CSS, Inter фонт
- Build алхамгүй (React, Node ашиглахгүй)

## Гаргасан шийдвэрүүд

1. **SQLite сонгосон**: Нэг файл, тохируулга шаардахгүй, 200 хэрэглэгчийн ачааллыг дийлнэ. WAL горим идэвхжүүлсэн.
2. **Session-д cookie ашигласан**: Нууц үг биш, утас/имэйлээр шууд нэвтрэх. Бичих үйлдэл бүрийг audit log-д бүртгэсэн.
3. **Эссэний баганыг огт хадгалахгүй**: Асуулт 2, 3, 5 (хувийн эссэ) ба Асуулт 4 нь DB-д орохгүй. Зөвхөн "Багийн сэдэв", "Яагаад энэ багт орсон", "Ижил зорилго" бэлэн тайлбарыг хадгалсан.
4. **Алхмуудыг хатуу түгжээгүй**: 1-7 чөлөөтэй, зөвхөн 8-р алхам (өдөр сонгох) нь 5-р алхамыг (төсөл бүртгэл) шаардна.
5. **Слот сонголтод DB transaction ашигласан**: `with_for_update()` дуудлага хоёр баг зэрэг сүүлийн суудлыг авахаас хамгаалсан.
6. **Овог нэрийг "phone email" хуудаснаас авсан**: "Багт хуваагдсан" хуудаст нэрийн багана байхгүй тул кодоор холбосон.
7. **Урсгал бүр тусдаа**: "1-р баг" гэх дугаар давхцахаас сэргийлж (track, number) хосоор ялгасан.
8. **Inter фонт**: Монгол Ө, Ү үсгийг бүрэн дэмждэг, Google Fonts-оос ачаалдаг.
